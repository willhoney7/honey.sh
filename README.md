# honey.sh

Personal site migrated to the Remix 3 beta app shape generated by `npx remix@next new`.

## App Shape

-   `app/routes.ts` defines the URL contract.
-   `app/actions/controller.tsx` owns top-level route actions.
-   `app/actions/posts/controller.tsx` owns nested post routes.
-   `app/router.ts` wires controllers and middleware.
-   `app/middleware/render.tsx` installs the request-scoped Remix UI renderer.
-   `app/ui/` holds shared document, layout, and page UI.
-   `app/data/posts.ts` loads markdown posts from `posts/`.
-   `app/assets.ts` owns the browser asset route used by the renderer.
-   `public/` contains static files served from the app root.

## Commands

```sh
npm install
npm run dev
npm test
npm run typecheck
```
